Open Data Initiative

CrimeAware API v1

Access real-time predictions, crime stats, and localized safety information programmatically. Free for researchers, NGOs, and students.

Base URL

https://crimeaware.india/api/v1

(Use your local host during development: http://localhost:5000/api/v1)

Endpoints

GET /states

Retrieve crime statistics and ML forecast data for all 36 Indian States and Union Territories.

curl -X GET http://localhost:5000/api/v1/states
GET /state/<name>

Retrieve specific crime statistics by querying the exact state or UT name.

curl -X GET http://localhost:5000/api/v1/state/maharashtra
GET /export/csv

Download the entire combined dataset (Historical + AI Predictions) as a CSV file for offline use.

curl -X GET http://localhost:5000/export/csv -o dataset.csv
