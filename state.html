📋 How to File an FIR in {{ state['state/ut'] }}

Step-by-step FIR Filing Guide ▼
  1. Go to the nearest police station — You can file at ANY station (Zero FIR allowed under BNSS 2023)
  2. Ask for the Duty Officer or SHO — They must record your complaint
  3. Narrate the incident clearly — Include date, time, place, accused description
  4. Get FIR copy — Police MUST give you a free signed copy (Section 154 CrPC)
  5. Note the FIR number — You will need this for follow-ups
  6. If refused: Send complaint by registered post to SP or approach Magistrate under Section 156(3)
Online FIR: Check your state police website for e-FIR facility. Many states now allow online FIR for select offences.
